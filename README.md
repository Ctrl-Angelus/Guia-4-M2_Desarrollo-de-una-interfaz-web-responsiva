## Tecnologias utilizadas 
* **HTML5** Estructura del sitio web.
* **CSS3** Estilos visuales, distribución responsiva y diseño adaptativo 
* **JavaScript** Interactividad y dinamismo de las interfaces.
* **Git & GitHub** Control de versiones y alojamiento del respositorio.
* **Visual Studio Code** Entorno de desarrollo. 

## Caracteristicas principales del sistema
* **Modo oscuro:** Temas oscuro y claro. 
* **Panel de estadisticas:** Visualización del stock disponible, alerta de bajo stock y valor total de inventario.
* **Tabla dinamica con filtros:** Lista de  y selector de categorias con filtrado.
* **Diseño Responsivo:** Interfaz adaptada a dispositivos móviles, tablets y escritorio.
* **Gestión dinámica de datos:** El sistema implementa un archivo centralizado en JavaScript `data.js`, que funciona como la base de datos principal de la aplicación. De este archivo se actualizan automáticamente el catálogo de productos y filtros, además de las métricas y tarjetas de estadísticas.
